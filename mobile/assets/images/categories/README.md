# Category Image Assets

Place category PNG images in this directory to display them inside the JoyEvents mobile Browse Events screen category carousel.

Expected image filenames:
- `music.png`
- `wedding.png`
- `corporate.png`
- `birthday.png`
- `sports.png`
- `cricket.png`
- `catering.png`
- `festival.png`
- `photography.png`

Recommended aspect ratio: 1:1 or 4:3 PNG/JPEG images.
